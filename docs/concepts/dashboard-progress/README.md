# Прогресс подготовки на дашборде (/main) — концепты

Задача #618: не реализация, а варианты того, каким сделать прогресс в шапке
дашборда вместо полукруглой шкалы. Рисунки — в `concepts.html`, открыть файлом
в браузере: четыре артборда подряд («Как сейчас», А, Б, В) и таблица сравнения.
Цвета и радиусы взяты из `admin/src/scss/colors.scss` (`--c1`, `--b0`, `--c2`,
`--bs-border-radius`), полукруг в первом артборде — копия `.sc-gauge` из
`admin/src/comps/TrainMethods/CoursesList.css`, чтобы сравнение было честным.

## Что не так с полукругом

* Дуга не читается как шкала: на 100 % она заполнена целиком и выглядит рамкой
  вокруг числа, на 40 % угол оценивается на глаз — засечек нет, сравнивать не с чем.
* Круг занимает четверть ширины карточки ради одного числа и ломает линию, по
  которой уже выстроены «Курсы / Модули / Топики».
* Число — единственный носитель смысла: из чего посчитаны проценты, с экрана не видно.

## Варианты (все горизонтальные)

* **А — «Дорожка»**. Шапка делится надвое: слева во всю высоту карточка
  разработчика, справа плитки и под ними полоса во всю ширину правой части —
  слева процент крупно, справа «62 из 148 топиков». Данные уже есть —
  `getTopStatsNew` считает `perc` и общее число топиков.
* **Б — «Ступени по курсам»**. Та же правая часть, горизонталь разрезана по курсам: каждый
  отрезок заполнен настолько, насколько закрыт курс, текущий подсвечен и подписан.
  Отвечает на «где я застрял», но требует процента по каждому курсу.
* **В — «Четвёртая плитка»**. Прогресс встаёт в общий ряд плиток с тонкой полосой
  под числом. Самый дешёвый, но прогресс весит столько же, сколько «12 модулей».

## Что рекомендую

А. Горизонталь в правой части шапки, число и остаток на одной строке, данные
текущие, правка локальная — `SemiCircle` меняется на полосу под плитками, слева
остаётся только блок разработчика во всю высоту. Б держать следующим шагом: когда на дашборд начнут приходить
проценты по курсам, «Дорожка» превращается в «Ступени» без перестройки шапки.
